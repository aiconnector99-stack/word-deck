# Word Deck for Android

This folder turns the Word Deck web app (`../index.html`) into an Android app
using [Capacitor](https://capacitorjs.com).

You don't need Android tools on your computer. GitHub builds the app:

1. Open the repository's **Actions** tab and pick **Build Android app**.
2. Open the newest run with a green check.
3. Under **Artifacts**, download **word-deck-android**. Unzip it to get
   `word-deck.apk`.

A new build runs automatically whenever `index.html` or this folder changes,
and you can start one by hand with **Run workflow**.
